# ESP32 Pressure Controller

ESP32 기반 압력 제어기 펌웨어와 한국어 터치 GUI 프로젝트입니다.

## 개발 상태

이 저장소는 현재 공개 배포 준비 중입니다. 검증된 프로젝트 소스와 OTA용 애플리케이션 이미지를
버전별로 추가할 예정입니다. 아직 공개 Release가 없으면 설치 가능한 OTA 업데이트도 없습니다.
하드웨어 검증을 하지 않은 버전을 검증 완료 제품으로 취급하지 마십시오.

## OTA 배포 방식

OTA 파일은 GitHub Releases를 통해 제공합니다. Wi-Fi는 OTA를 위해 사용자가 명시적으로 켤 때만
사용하는 방식으로 개발합니다. 업데이트 확인 결과가 최신이면 끄고, 새 버전의 검증·설치를 마친 뒤에도
끄도록 합니다. 오류가 발생하면 오류를 알린 뒤 끄며 무한 자동 재시도를 하지 않습니다.

배포 시 애플리케이션 이미지, 보드·버전 정보와 SHA-256을 함께 제공합니다. 다른 보드용 이미지나
부트로더·설정 영역이 합쳐진 전체 플래시 이미지를 OTA 애플리케이션 파일로 사용하지 마십시오.
